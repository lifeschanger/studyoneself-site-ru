# studyoneself.ru

Русская страница-визитка Study Oneself. Один HTML, без сборки.

На телефоне одна колонка. С планшета портрет стоит рядом с текстом, карточки — в ряд, между портретом и карточками есть зазор. С широкого экрана первый экран — три полосы обложки. Подпись, блок «О проекте», текст у портрета, темы, хайку и блок «Нужны люди» растут вместе с колонкой.

Индексация закрыта (`noindex`), пока домен `studyoneself.ru` не привязан. Страница публикуется через GitHub Pages. Домен подключает Владислав на reg.ru.

Светлый макет в этот репозиторий не входит.
